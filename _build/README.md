# 文档生成说明

本目录是《储粮安全物联网监控平台》三份配套材料的生成源码。
修改内容后，可一键重新生成 Word 文档与预览 PDF（全文宋体）。

## 交付物（在上一级目录）

| 文件 | 说明 |
| --- | --- |
| `储粮安全物联网监控平台-项目简介与BP-PPT编制指南.docx` | 项目简介 + BP/PPT 写作指南，全文宋体，62 页 |
| `储粮安全物联网监控平台-项目简介与BP-PPT编制指南(预览版).pdf` | 与 docx 同源的 PDF 预览 |
| `储粮安全物联网监控平台-商业计划书设计纲要.docx` | 商业计划书写作的“施工图”，全文宋体，25 页 |
| `储粮安全物联网监控平台-商业计划书设计纲要(预览版).pdf` | 与 docx 同源的 PDF 预览 |
| `储粮安全物联网监控平台-商业计划书简略样板.docx` | 压缩样板，演示写法，全文宋体，32 页 |
| `储粮安全物联网监控平台-商业计划书简略样板(预览版).pdf` | 与 docx 同源的 PDF 预览 |

三份材料的分工：

- **项目简介与BP-PPT编制指南**：项目内容总纲（定位、痛点、方案、技术、市场、商业模式、团队、风险、规划）+ 第十章商业计划书编制指南 + 第十一章路演 PPT 编制指南。
- **商业计划书设计纲要**：只讲“怎么写”，逐章设计卡（写作目标/篇幅/结构骨架/必备要素/需要的数据/配图/常见失分点/示范句式）+ 图表清单 + 数据采集清单 + 写作排期 + 四类定稿自检清单。
- **商业计划书简略样板**：只讲“写成什么样”，保留完整章节骨架，每章压缩到真实篇幅的三分之一，可直接对照扩写。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `docgen.py` | 排版引擎：宋体字体、标题层级、表格、提示框、目录域、页眉页脚等基础模块 |
| `content_a.py` | 项目简介正文第一部分：前言 ~ 第六章（定位、痛点、方案、技术、市场、商业模式） |
| `content_b.py` | 项目简介正文第二部分：第七章 ~ 附录（团队、风险与合规、规划、BP 指南、PPT 指南） |
| `bp_outline.py` | 商业计划书设计纲要正文 |
| `bp_sample.py` | 商业计划书简略样板正文 |
| `fontfix.py` | 保存后归一化字体：清除模板残留的主题字体与 Courier，确保全文有效字体为宋体 |
| `make.py` | 构建项目简介（两遍编译：第一遍取页码，第二遍写入目录） |
| `make_bp.py` | 构建商业计划书设计纲要与简略样板（同样两遍编译） |
| `extract_toc.py` | 从渲染出的 PDF 中提取各级标题的真实页码 |
| `verify.py` | 项目简介自检：宋体覆盖、表格右边界溢出、标题孤行、目录页码 |
| `verify_bp.py` | 商业计划书两份文档的同类自检 |
| `render.py` / `render_bp.py` | 将 PDF 逐页导出为 PNG，便于排版检查 |
| `toc.json`、`_toc_*.json` | 上一次构建时提取到的标题页码 |
| `pdf/`、`png/` | 构建过程中生成的 PDF 与逐页 PNG |

## 重新生成文档

```bash
cd _build
python make.py       # 重新生成 项目简介与BP-PPT编制指南
python make_bp.py    # 重新生成 商业计划书设计纲要 + 简略样板
python verify.py     # 项目简介自检（路径已内置，无需参数）
python verify_bp.py  # 商业计划书两份文档自检
python render.py     # 逐页导出 PNG
python render_bp.py  # 商业计划书两份文档逐页导出 PNG
```

脚本会自动完成：生成 docx → 归一化字体 → 调用 LibreOffice 转 PDF → 提取页码 → 重新生成带完整目录的 docx → 再次转 PDF 校验。

## 修改内容

- 改文字、表格、章节：编辑 `content_a.py` / `content_b.py`（项目简介）、`bp_outline.py` / `bp_sample.py`（商业计划书两份）。内容以 `('类型', 内容)` 的形式按顺序排列。
- 支持的内容类型：`h1` 一级标题、`h2` 二级标题、`h3` 三级标题、`p` 正文段落、`b1`/`b2` 项目符号、`note` 提示框（内容为 `(标签, 正文)` 二元组）、`fig` 图示占位说明、`tbl` 表格、`cap` 表格标题、`pb` 分页。
- 改字体、行距、页边距、封面样式：编辑 `docgen.py`。

**如果生成的 docx 正在 WPS 或 Word 中打开**，脚本会自动改存为 `……(新版本).docx` 并给出提示。想覆盖原文件，请先关闭文档再运行。

## 注意

- 表格内容（`tbl`）中每一行的列表元素个数必须与 `cols` 的列数一致；少一个闭合符号会导致文档无法生成。
- 文档正文要求使用宋体，`docgen.py` 中的 `FONT = '宋体'` 控制全局字体，不建议改动。
- 表格标题（`cap`）与表格（`tbl`）必须相邻且顺序正确，排版引擎依赖 `keepNext` 链把标题与表头固定在同一页；如新增表格，请保持这一写法。
- 提示框（`note`）已设置「段中不分页」（`keep_together`），保证灰底提示框不会被分页截断。
- `w:pPr` / `w:trPr` 的子元素必须按 OOXML 规定顺序插入，直接 `append` 会被渲染器静默忽略（这正是「表格标题孤立页底」的根因）。如需新增此类属性，请复用 `docgen.py` 中 `keep_with_next`、`_trpr_set`、`para_mark_size` 的写法。
- 目录行高使用固定值（`line_exact`），避免中文字体度量差异导致目录溢出到第二页。
- 目录是「预填内容 + 可更新域」的组合：打开文档即可看到完整目录与页码，在 Word 中右键「更新域」可按 Word 自身排版重算页码。
- 正文中 `【待填】`、`【需核实】` 均为待团队用真实数据/权威口径替换的占位标记，不是排版缺陷。
